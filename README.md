# Reservoir Simulation Project  

A simple reservoir engineering project demonstrating computational modeling, data processing, and visualization.  

## Tools Built  
1. **Computational Model**: `reservoir_simulation.py`  
   - Simulates flow rates using Darcy’s law.  
2. **Data Pipeline**: `data_processing.py`  
   - Processes permeability data.  
3. **Visualization Tool**: `visualization.py`  
   - Generates porosity-permeability plots.  

## How to Run  
1. Clone this repository.  
2. Run:  
   ```bash  
   python data_processing.py  
   python visualization.py  
   python reservoir_simulation.py
